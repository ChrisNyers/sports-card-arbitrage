## What Was Built This Session

### 1. Card Identity Schema (`cardarb/models/card_identity.py`)

A canonical definition for any card with 20+ attributes:

```python
CardIdentity(
    sport="football",
    player_name="Patrick Mahomes",
    player_position="QB",
    year=2020,
    manufacturer="Panini",
    product="Donruss",
    card_number="201",
    parallel="Red",
    parallel_count=100,
    grading_company="PSA",
    grade=8.0,
    cert_number="12345678",
    identity_confidence=0.98,  # Can we be certain this is the same card?
)
```

**Key Features:**
- Confidence scoring (0.0-1.0): Can only compare prices if confidence > 0.95
- `canonical_key()`: Deterministic identifier for matching across markets
- `short_description()`: Human-readable card name
- `CardIdentityMatcher`: Fuzzy matching for player names + fuzzy string distance

**Validation:**
- Two cards with confidence 0.98 → can compare prices ✓
- Two cards with confidence 0.85 → cannot compare, need more data ✗

### 2. Data Provenance Wrapper (`cardarb/models/data_record.py`)

Every price/population/listing point includes source & freshness:

```python
DataRecord.price_record(
    value=145.00,
    source="eBay (sold listing)",
    source_url="https://ebay.com/itm/...",
    data_age_minutes=4,  # How old is the data?
    confidence=0.98,  # How reliable is this source?
    sale_type="fixed-price",
    seller_rating=4.9,
)
```

**Key Features:**
- `is_current()`: Data fresh enough to use? (configurable threshold)
- `recency_score()`: 1.0 for <1hr old, 0.5 for 24+ hours old
- `age_description()`: "3m ago", "2d ago", "1w ago"
- `DataSnapshot`: Immutable capture of all data for a recommendation
- `can_recommend()`: Do we have fresh enough data to make a call?

**Validation:**
- Price from 4 minutes ago → `is_current()` = True ✓
- Population data from 40 hours ago → `is_current(max_age_hours=24)` = False ✗

### 3. Sold-Comparable Engine (`cardarb/models/comparables.py`)

Analyzes sold listings to determine fair value:

```python
listings = [
    SoldListing(price=145, sold_date=3_days_ago, sale_type="fixed-price", ...),
    SoldListing(price=142.50, sold_date=5_days_ago, sale_type="auction", ...),
    SoldListing(price=148, sold_date=8_days_ago, sale_type="fixed-price", ...),
    SoldListing(price=250, sold_date=20_days_ago, ...),  # Outlier
]

analysis = ComparableAnalyzer.analyze(listings)
# Returns: ComparableSalesAnalysis
```

**Key Features:**
- **Outlier removal**: IQR method removes $250 sale (likely mislabeled)
- **Duplicate removal**: Same seller, same day → keep highest price
- **Recency weighting**: Recent sales have more confidence
- **Dispersion analysis**: Std dev tells us how consistent the market is
- **Confidence scoring**: Based on sample count, dispersion, data age
- **Uncertainty estimation**: ±$ range that accounts for market variation
- **Buy recommendation**: Is this asking price a good deal?

**Example Output:**
```
Fair Value: $144.50
  (Trimmed Mean: $145.25)
  (Range: $140 - $148)

Dispersion: 2.8% (std dev: $4.10)
Confidence: 92%
Uncertainty: ±$6.20

Sample: 4 sales (2 auctions, 2 fixed-price)
Recency: 9 days median, 85% freshness

Ask $130: BUY (potential profit: $14.50)
Ask $145: PASS (at fair value)
Ask $160: PASS (above fair value)
```

### Test 4: Full Integration (1.5 hours)

Put it all together:

```python
# 1. Create card identity
card = CardIdentity(
    sport="football",
    player_name="Patrick Mahomes",
    year=2020,
    manufacturer="Panini",
    product="Donruss",
    card_number="201",
    grading_company="PSA",
    grade=8.0,
    identity_confidence=0.98,
)

# 2. Load sold data with provenance
sold_listings = [
    SoldListing(price=145, ...),
    # ... more listings
]

# 3. Convert to DataRecords
sold_records = [
    DataRecord.price_record(s.price, "eBay", data_age_minutes=300) 
    for s in sold_listings
]

# 4. Create snapshot
snapshot = DataSnapshot(
    card_id=card.canonical_key(),
    sold_prices=sold_records,
)

# 5. Check if we can recommend
can_rec, reason = snapshot.can_recommend()
if can_rec:
    # 6. Analyze comparables
    analysis = ComparableAnalyzer.analyze(sold_listings)
    
    # 7. Determine fair value
    fair_value = analysis.weighted_estimate()
    print(f"Fair value: ${fair_value} (confidence: {analysis.confidence:.0%})")
```

## Edge Cases to Watch

| Scenario | Test With | Expected Behavior |
|----------|-----------|-------------------|
| Sparse data (1-2 sales/year) | Less popular players | Confidence should be low (<60%) |
| High dispersion (prices vary widely) | Different graded versions mixed | Dispersion >15%, uncertainty high |
| Stale data (all >60 days old) | Older cards, less trading | Confidence lower due to age |
| Outliers (huge price spikes) | Card with one anomalous sale | Should be identified and removed |
| No sales data | Brand new card or variant | Fair value = None, can't recommend |
